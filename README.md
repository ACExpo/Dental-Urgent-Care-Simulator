# Dental Urgent Care Simulator

Interactive clinical decision-making activity for fourth-year (D4) dental students.

## Course assignment
MED 0620 — Technology in Health Professions Education

## Included cases
1. Endodontic emergency: symptomatic irreversible pulpitis
2. Surgical emergency: nonrestorable tooth
3. Odontogenic infection: localized acute apical abscess

Each case has three sequential decisions: clinical assessment, working diagnosis/prognosis, and urgent management. Responses receive immediate feedback. A score and case-by-case summary appear at the end.

## Run offline
1. Open `index.html` from this repository.
2. Click **Raw** and save the page as `Dental_Urgent_Care_Simulator.html`.
3. Double-click the saved HTML file to open it in Chrome, Edge, Safari, or Firefox.
4. Email the saved HTML file as an attachment with the lesson plan. If your email blocks HTML files, compress it as ZIP first.

No installation, server, account, tracking, or patient data is required.

**Educational use only.** All cases are fictional. Decisions require faculty review and adaptation to institutional policies.
